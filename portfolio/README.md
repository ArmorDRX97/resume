# Как готовить проекты для переноса в портфолио

Папка `portfolio` временная. В нее можно складывать материалы по проектам, а затем я перенесу их в структуру сайта.

## Структура одного проекта

```text
portfolio/
  project-name/
    meta.txt
    cover.png
    gallery/
      01-home.png
      02-mobile.png
      03-detail.png
```

## Обязательные файлы

- `meta.txt` — описание проекта, тип, ссылка, плашки и тексты для карточки.
- `cover.png` или `cover.jpg` — изображение для карточки проекта.

## Поведение карточки на сайте

Если внутри проекта есть папка `gallery`, значит карточка на сайте должна открывать боковую панель с галереей. В этой панели можно показать скриншоты, описание, плашки и кнопку на внешний сайт, если ссылка указана в `meta.txt`.

Если папки `gallery` нет, значит клик по карточке должен сразу вести на внешний сайт из поля `url` с `target="_blank"`.

## Шаблон meta.txt

```text
title: Название проекта
type: site
url: https://example.com
tags: Site, Responsive, UI/UX, Frontend
year: 2026
role: UI/UX, frontend
priority: 1

short:
Короткое описание для карточки.

description:
Подробное описание проекта: задача, формат, что было сделано и чем полезен результат.

features:
- Первый важный пункт
- Второй важный пункт
- Третий важный пункт

result:
Что получил клиент, команда или пользователь.
```

## Типы проектов

- `site` — готовый сайт по внешней ссылке.
- `prototype` — кликабельный HTML-мокап или интерактивный прототип.
- `design` — дизайн-кейс со скриншотами.
- `presentation` — презентации, баннеры, листовки и другая графика.

## Имена файлов

Используй латиницу, цифры и дефисы:

```text
cover.png
01-home.png
02-mobile.png
03-dashboard.png
```

Не используй пробелы, кириллицу и спецсимволы в названиях файлов.
